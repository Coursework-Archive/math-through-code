# Transformations Sheet
## Identify Base Function
- x² → parabola  
- √x → square root  
- |x| → absolute value  
- 1/x → rational  
- sin x, cos x → trig  

- Inside = affects **x** → horizontal changes  
- Outside = affects **f(x)** → vertical changes
## Shifts
### Vertical (outside)
- f(x) + c → up  
- f(x) - c → down
### Horizontal (inside)
- f(x - c) → right  
- f(x + c) → left  
- -f(x) → reflect over x-axis  
- f(-x) → reflect over y-axis  
## Scaling
### Vertical (outside)
- a·f(x), a > 1 → stretch  
- 0 < a < 1 → compress
### Horizontal (inside)
- f(ax), a > 1 → compress  
- f(ax), 0 < a < 1 → stretch
## Order of Transformations
1. Inside (horizontal)
2. Outside (vertical)

## Quick Recognition
- f(x + 3) → left  
- f(x - 3) → right  
- f(x) + 3 → up  
- 2f(x) → vertical stretch  
- f(2x) → horizontal compression  
- -f(x) → flip over x-axis

## Slope
slope = (change in output) / (change in input)
**Formula:**
m = (f(b) - f(a)) / (b - a)

OR

m = (y₂ - y₁) / (x₂ - x₁)


## Removable discontinuity 
Cancel → hole
Left in denominator → asymptote


## Tangent Line at a Given Point

1. Find the derivative f'(x) -This gives the **slope formula**.
2. Plug the x-value into the derivative m = f'(a) This gives the **slope of the tangent line**.
3. Find the point on the curve So the point is: (a, f(a)) If the point is already given, use it.
4. Use point-slope form Substitute the slope and point into y - y_1 = m(x - x_1)
5. Simplify if needed Leave in point-slope form or simplify to slope-intercept form if asked.

### What each step gives you

- \(f'(x)\) → slope formula
- \(f'(a)\) → slope at the point
- \(f(a)\) → y-value of the point
- point-slope form → tangent line equation

### Quick reminder

- Plug into **derivative** to get the **slope**
- Plug into **original function** to get the **point**

### Pattern: Implicit Differentiation — Starting Steps

Step 1: Differentiate BOTH sides with respect to x
- Treat y as a function of x → every y becomes y′ when differentiated

Step 2: Apply rules term-by-term
- Power rule (x terms normal)
- Product rule (if x·y or anything multiplied)
- Chain rule (if y is inside trig, exponent, root, etc.)

Step 3: Add y′ to every derivative involving y
- d/dx(y) = y′
- d/dx(y^2) = 2y·y′
- d/dx(sin y) = cos(y)·y′

Step 4: Group all y′ terms on one side
- Factor out y′

Step 5: Solve for y′
- Divide to isolate y′

Step 6: Simplify (only if clean)
